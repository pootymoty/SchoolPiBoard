# SchoolPi.Tariffs

Сервис тарифов основного сайта (school-pi.online, репозиторий
`my_portfolio_project`, Flask) — подписки на ИИ-функции и оплата через
Робокассу.

Держит только это:

- каталог тарифов (`Configuration/TariffOptions.cs`, `TariffPlans`);
- подписку пользователя основного сайта (по его же числовому id,
  собственных учётных записей здесь нет);
- оплату: ссылку на Робокассу и приём её уведомления об оплате.

Не держит: пароли, почту, лимиты токенов, счётчик бесплатных попыток —
всё это остаётся на основном сайте, у него уже есть таблица расхода ИИ
(`AiUsage`), и здесь её дублировать незачем.

Развёртывание — `../docs/deploy.md`. Протокол Робокассы и структура
`RobokassaService`/`SubscriptionService` — копия того же приёма, что уже
работает в `online/server` (биллинг онлайн-доски), адаптированная под
другой каталог тарифов и без собственной системы пользователей.

## API

Все пути, кроме `/health`, `/plans` и `/robokassa/result`, требуют
заголовок `X-Api-Key` с секретом, общим с основным сайтом
(`TARIFFS_API_KEY`).

- `GET /health` — жив ли сервис.
- `GET /plans` — каталог тарифов (ключ, название, цена).
- `GET /status/{externalUserId}` — текущая подписка или `null`.
- `POST /checkout` `{externalUserId, plan, email?}` → `{paymentUrl}`.
- `POST|GET /robokassa/result` — ResultURL Робокассы, здесь включается
  подписка. Защищён подписью Робокассы (Password2), не ключом сайта.
