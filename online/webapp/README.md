# SchoolPiBoard — веб-приложение

React + TypeScript + Vite. Сайт онлайн-доски school-pi-board.online.

С десктопным приложением и его сервером лицензий этот проект не связан
ничем: отдельный домен, отдельный бэкенд, отдельная база, отдельные
учётные записи.

## Запуск

```bash
cd online/webapp
npm install
cp .env.example .env
npm run dev            # http://localhost:5173
```

Порт 5173 зафиксирован: он же перечислен в `Site:AppOrigins` на сервере,
иначе браузер не пустит приложение к API.

```bash
npm run build          # проверка типов + сборка в dist/
npm run typecheck
```

## Страницы

| Путь | Что там |
|---|---|
| `/` | главная: крупные «ВОЙТИ» и «ЗАРЕГИСТРИРОВАТЬСЯ», описание, тарифы, правовые ссылки |
| `/register` | регистрация: фамилия, имя, дата рождения, почта, пароль дважды, капча |
| `/login` | вход; сюда же ведёт регистрация с напоминанием подтвердить почту |
| `/confirm?token=` | страница из письма: подтверждает регистрацию |
| `/subscribe` | пробный период или покупка подписки |
| `/boards` | мои доски: постранично по 10, чужие помечены 🔗 |
| `/boards/:id` | доска: присутствие, участники, ссылки-приглашения |
| `/profile` | подписка, имя, пароль, удаление учётной записи |
| `/profile/delete?token=` | страница из письма: подтверждает удаление |
| `/join/:token` | вход на доску по ссылке-приглашению |
| `/legal/terms`, `/legal/privacy`, `/legal/offer` | правовые тексты |

## Фон главной страницы

`components/BookshelfBackground.tsx` — книжные полки. Сейчас статичные:
анимация (дрожание под курсором, пыль, выпадающие при прокрутке книги)
добавляется внутри этого компонента и в стилях `.shelf` / `.book`,
не затрагивая разметку страниц. Фон подключён только к главной — на рабочих
страницах он мешал бы.

## Капча

`components/Captcha.tsx` — Yandex SmartCaptcha. Если `VITE_CAPTCHA_SITEKEY`
пуст, виджет не показывается и наружу отдаётся пустой токен; сервер в режиме
разработки проверку тоже не выполняет. В бою и ключ сайта, и серверный ключ
обязательны — без них сервис не стартует.

## Решения

**Права проверяет сервер.** Фронтенд прячет кнопки, которые роли не положены,
но это удобство, а не защита: скрытая кнопка ничего не запрещает.

**После обрыва связи клиент не «догоняет» пропущенные события.** SignalR
переподключается, после чего заново вызывается `JoinBoard`, возвращающий
состояние комнаты целиком.

**Ссылку-приглашение видно только один раз** — при создании: на сервере
хранится её хеш, восстановить ссылку оттуда нельзя. Это же не даёт достать
чужие ссылки из базы.
