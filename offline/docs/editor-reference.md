# Редактор доски: полный функционал офлайн-версии

Справочник для переноса на онлайн-доску. Всё описанное реализовано
и работает в десктопной версии 2.2.1.

## Экраны

1. **Список досок** — открывается при запуске.
2. **Редактор** — открывается по клику на строку доски.

## Список досок

Шапка: заголовок, кнопка «Архив» (переключает список на архивные и обратно),
шестерёнка «Настройки», кнопка «+ Новая доска».

Панель фильтров:

- поле поиска по названию с плейсхолдером и крестиком очистки;
- выпадающий список периода: «За неделю», «За месяц», «За полгода»;
- кнопка направления сортировки со стрелкой и подписью «Сначала новые» /
  «Сначала старые».

Таблица: колонки «Название», «Создана», «Изменена» и кнопка «⋯» в конце строки.
Клик по строке открывает доску. Меню «⋯»: Открыть, Переименовать,
В архив / Вернуть из архива, разделитель, Удалить.

Внизу — пагинация: ««», «‹», номера страниц, «›», «»» и текст с номером
страницы. При пустом списке вместо таблицы показывается подсказка.

Доски старше 30 дней помечаются как архивные (`ArchiveAfterDays = 30`).

## Редактор: раскладка

Холст занимает весь экран. Поверх него плавающие панели:

| Где | Что |
|---|---|
| Верх слева | навигация и название доски |
| Верх справа | индикатор сохранения и кнопки режимов |
| Низ по центру | панель инструментов |
| Низ справа | масштаб |
| Слева, по вызову | панель параметров активного инструмента |
| Над выделением | панель действий с объектом |

Все всплывающие панели закрываются кликом по холсту и клавишей Esc.
Панель параметров рисующего инструмента прячется сразу при начале рисования,
чтобы не перекрывать холст.

## Верхняя панель

Слева: «⌂» — к списку досок; название доски; «✎» — переименовать.

Справа:

| Кнопка | Действие |
|---|---|
| текст | индикатор состояния сохранения |
| ⏱ | панель таймера |
| ? | справка по действиям |
| ⤢ | показать всё содержимое (вписать в экран) |
| 💾 | экспорт в PNG |
| ⚙ | панель «Форматирование фона» |

## Нижняя панель инструментов

Слева направо:

| Кнопка | Назначение |
|---|---|
| ↶ | отменить |
| ↷ | повторить |
| *разделитель* | |
| стрелка | Курсор |
| ✋ | Рука |
| ✏ | Перо 1 |
| ✏ | Перо 2 |
| 🖍 | Маркер |
| 🧽 | Ластик |
| T | Текст |
| ▭ | Фигуры |
| 🖼 | Вставить изображение (сразу открывает файловый диалог) |
| *разделитель* | |
| ✕ | Очистить доску |

Перо 1, Перо 2 и Маркер — три независимых набора настроек: у каждого свой
цвет, толщина и прозрачность. На кнопке каждого показана точка его текущего
цвета.

Инструменты Курсор, Рука, Перо 1, Перо 2, Маркер, Ластик, Текст, Фигуры —
переключатели: активен ровно один. Повторный клик по активному рисующему
инструменту открывает его панель параметров.

«Очистить доску» спрашивает подтверждение и откатывается через Ctrl+Z.

## Панель масштаба

«−», текущее значение в процентах, «+». Клик по значению возвращает 100 %.

Масштаб колесом мыши — плавный, коэффициент пропорционален величине прокрутки
(около 1.15× за щелчок), с привязкой к точке под курсором. Пределы: 2 % … 2000 %.

## Панели параметров инструментов

### Перо 1, Перо 2, Маркер

- **Размер** — 6 вариантов: 1, 5, 10, 15, 20, 30.
- **Прозрачность** — 5 вариантов: 20, 40, 50, 70, 100 %.
- Живой предпросмотр линии текущими параметрами.
- Палитра цвета.

### Фигуры

- Выбор фигуры: Линия, Стрелка, Прямоугольник, Эллипс, Треугольник,
  Трапеция, Параллелограмм, Ромб.
- **Толщина** — те же 6 вариантов.
- **Тип линии** — кнопка открывает список: Сплошная, Штрих, Штрихпунктир,
  Пунктир. У каждого пункта нарисован образец.
- Палитра цвета.

### Ластик

- **Размер** — 5 фиксированных вариантов: 8, 16, 26, 60, 120.
- Круг стирания показан на холсте под курсором. При быстром движении
  визуальный радиус растёт (до +55 % при скорости 2400 px/с).

### Форматирование фона

- **Цвет** — сетка образцов, 5 в ряд.
- **Сетка** — 9 стилей: Сплошная, Точка, Квадрат, График, Гибридная, Ромб,
  Широкий фильтр, Треугольник, Узкий фильтр. У каждого превью.
- **Цвет разлиновки** — палитра.

Панель прокручиваемая.

## Палитра цвета

Общий компонент. Образцы цветов, опционально пункт «Без цвета», и вызов
отдельного окна выбора: круг оттенка, квадрат насыщенности и яркости,
поле HEX, кнопки «Выбрать» и «Отмена».

## Панель выделенного объекта

Появляется над выделением, позиция пересчитывается при изменении размера
холста и прокрутке.

| Кнопка | Действие |
|---|---|
| образец заливки | цвет заливки |
| образец границы | цвет границы |
| образец линии | тип линии (только для линий, стрелок и контуров фигур) |
| T | текст внутри объекта |
| ⧉ | копировать (Ctrl+C) |
| 🗑 | удалить (Delete) |
| ⋯ | меню: На передний план, На задний план, разделитель, Дублировать |

Кнопка типа линии скрыта, если у выделенного объекта её нет.

## Инструменты и приёмы

### Курсор

- Клик по объекту — выделить.
- **Ctrl + клик** — добавить объект к выделению или убрать из него.
- Перетаскивание выделенного — перемещение.
- Клик по пустому месту и протяжка — **свободное лассо**.
- **Shift + протяжка** — **прямоугольная рамка** выделения.
- **Двойной клик** по фигуре или надписи — ввод текста внутри неё.
- **Пробел (удерживая)** — временное переключение на перемещение холста.

### Рука

Перемещение холста перетаскиванием.

### Перо 1, Перо 2, Маркер

- Рисование от руки.
- **Shift** во время рисования — ровная линия с привязкой угла к шагу 15°.
- **Автовыпрямление**: задержать перо на месте, не отпуская кнопку, —
  через 500 мс штрих превращается в прямую. Срабатывает, только если штрих
  длиннее 45 px и уже близок к прямой (отклонение до 10 %).
- **Объединение штрихов**: если следующее касание начато не позже 500 мс
  после предыдущего, не дальше 25 экранных px от его конца и тем же
  инструментом с теми же параметрами — оба касания становятся одним объектом,
  но остаются раздельными сегментами внутри него. Соседние буквы поэтому
  не соединяются линией, а Ctrl+Z отменяет последнее касание, а не всё слово.
- Маркер рисуется полупрозрачным и плоским пером.

### Ластик

- Стирает по кругу текущего размера.
- **Изображения не затрагивает вообще** — картинка удаляется только кнопкой.
- Фигуры, текст и стрелки удаляются целиком при попадании.
- **Прямая-фигура** остаётся одним объектом: следы стирания записываются
  в отдельный список областей и вырезаются при отрисовке.
- **Рукописный штрих** остаётся одним объектом: после частичного стирания
  внутри него хранятся оставшиеся сегменты, новые объекты не создаются.

### Текст

Клик по холсту создаёт надпись и открывает поле ввода поверх холста.
Размер шрифта поля подстраивается под масштаб.

### Фигуры

- Протяжка строит фигуру.
- **Shift** — правильная фигура (квадрат, круг и т. д.), для линий и стрелок —
  привязка угла к шагу 15°.

### Изображения

- Кнопка 🖼 — выбор файла: png, jpg, jpeg, bmp, gif, webp, tif, tiff.
- **Ctrl+V** вставляет изображение из буфера обмена. Поддерживаются несколько
  представлений: BitmapSource, PNG, JPEG, BMP, DIB — иначе картинки
  из мессенджеров не вставляются.
- Если в буфере нет изображения, вставляется текст; если и его нет —
  вставляются ранее скопированные объекты доски.

## Навигация по холсту

- **Средняя кнопка мыши** — перемещение, всегда, при любом инструменте.
- **Пробел + правая кнопка** — то же самое.
- **Колесо** — масштаб.
- Полос прокрутки нет. Холст бесконечен, границ нет.
- Курсор во время перемещения — «ScrollAll», удерживается принудительно.

## Трансформация

Ручки показываются **только** для фигур, изображений и текста:
8 ручек по габаритам (углы и середины сторон) и отдельная ручка вращения
на 30 px выше верхней границы.

**Линии, стрелки и выпрямленные штрихи** пера и маркера получают вместо этого
**две ручки на концах**. Перетаскивание одного конца оставляет второй
неподвижным и меняет одновременно длину и угол.

**Обычные рукописные штрихи ручек не получают вовсе** — только перемещение.

Курсор меняется по типу ручки: диагональные, вертикальная, горизонтальная,
рука для вращения.

## Клавиатура

| Сочетание | Действие |
|---|---|
| Ctrl+Z | отменить |
| Ctrl+Y | повторить |
| Ctrl+C | копировать |
| Ctrl+X | вырезать |
| Ctrl+V | вставить |
| Ctrl+D | дублировать |
| Ctrl+A | выделить всё |
| Ctrl+S | сохранить |
| Delete, Backspace | удалить выделенное |
| Esc | закрыть панели, снять выделение, вернуться к Курсору |
| Пробел (удерживая) | временное перемещение холста |
| Shift (при рисовании) | ровная линия / правильная фигура |
| Shift (при выделении) | прямоугольная рамка вместо лассо |
| Ctrl (при клике) | добавить объект к выделению |

## Справка «?»

Панель со списком приёмов — те же строки, что перечислены выше:
перемещение, масштаб, ровная линия, автовыпрямление, правильная фигура,
выделение рамкой, добавление к выделению, текст в фигуре, отмена/повтор,
копирование, дублирование, выделить всё, удаление, возврат к курсору.

## Таймер

Круговой индикатор с оставшимся временем, минуты и секунды крупно.
Кнопки: «◻» сброс, «−» минус минута, «+» плюс минута, «▶» пуск/пауза.

Минуты и секунды меняются кликом по числу — открывается ввод значения.
Диапазон: 1…180 минут, секунды 0…59.

По истечении показывается сообщение «Время вышло» с кнопкой «Хорошо» —
оно появляется даже если панель таймера закрыта.

## Экспорт в PNG

Кнопка 💾. Экспортируется область содержимого доски. Если доска пуста,
показывается сообщение и экспорт не выполняется. Имя файла по умолчанию —
название доски.

## Сохранение

Автосохранение каждые 3 секунды при наличии изменений, плюс Ctrl+S.
Состояние показывается индикатором в шапке.

При открытии доски показывается индикатор загрузки.

## Модель объекта доски

Один тип на все объекты, без наследования — так сериализация остаётся простой.

| Поле | Назначение |
|---|---|
| `Id` | идентификатор |
| `Kind` | Stroke, Shape, Text, Image |
| `Shape` | Line, Arrow, Rectangle, Ellipse, Triangle, Trapezoid, Parallelogram, Rhombus |
| `LineStyle` | Solid, Dash, DashDot, Dot |
| `X`, `Y`, `W`, `H` | габариты в мировых координатах, без учёта поворота |
| `Rotation` | поворот в градусах вокруг центра габаритов |
| `Z` | порядок отрисовки, больше — выше |
| `StrokeColor`, `FillColor` | пустая строка в заливке означает «без заливки» |
| `Thickness`, `Opacity` | |
| `Marker` | штрих маркера: полупрозрачный, плоское перо |
| `StrokeSource` | Pen, Pen2 или Marker |
| `IsStraightStroke` | штрих был выпрямлен через Shift или удержанием |
| `Points` | плоский список координат x0,y0,x1,y1,… |
| `StrokeSegments` | сегменты составного штриха; пустой список — старый формат |
| `ErasePoints` | вырезанные ластиком области: x,y,radius,… в локальных координатах |
| `Text`, `FontSize`, `TextColor` | |
| `ImageBase64` | изображение |

Доска дополнительно хранит название, даты создания и изменения, признак
архива, цвет фона, стиль сетки и цвет разлиновки.

## Настройки приложения

Диалог по шестерёнке в списке досок:

- **Хранение данных** — папка с файлом досок, кнопки «Выбрать папку…»,
  «По умолчанию», «Открыть в проводнике». При смене папки спрашивается,
  переносить ли существующие доски.
- **Лицензия** — кнопка «О программе и лицензии».

## Чего в офлайн-версии нет

Слоёв, группировки объектов, направляющих и привязки к сетке, поиска
по содержимому доски, шаблонов, комментариев, истории версий.
