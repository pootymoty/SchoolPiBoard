## 2. Термины и определения

**Программа** — программа для ЭВМ «SchoolPiBoard», предназначенная для
рисования и работы с графическими объектами на виртуальной доске,
устанавливаемая на компьютер Пользователя под управлением операционной
системы Windows.

**Правообладатель** — лицо, которому принадлежит исключительное право
на Программу, указанное в разделе «Реквизиты Правообладателя».

**Пользователь** — лицо, принявшее условия настоящей Оферты.

**Стороны Договора (Стороны)** — Правообладатель и Пользователь.

**Лицензия** — простая (неисключительная) лицензия, то есть право
использования Программы в пределах, установленных настоящим Договором,
с сохранением за Правообладателем права выдачи лицензий другим лицам.

**Лицензионный ключ (Ключ)** — уникальная последовательность символов,
предоставляемая Пользователю и необходимая для активации Программы.

**Активация** — подтверждение права использования Программы путём ввода
Ключа в Программе и его проверки на сервере Правообладателя.

**Устройство** — отдельный компьютер, на котором активирована Программа.

**Пробный период** — срок, в течение которого Программа предоставляется
для использования без оплаты.

**Сайт Правообладателя** — сайт в сети «Интернет» по адресу
https://school-pi.online

**Акцепт** — полное и безоговорочное принятие Пользователем условий
настоящей Оферты путём совершения действий, указанных в разделе 4.

3.1. Правообладатель предоставляет Пользователю Лицензию на использование
Программы, а Пользователь обязуется уплатить вознаграждение в размере

3.2. Исключительное право на Программу Пользователю не передаётся
и не отчуждается. Пользователь получает только право использования
Программы способами и в пределах, установленных настоящим Договором.

3.3. **Пределы использования:**

3.3.1. **Территория** — все страны мира.

3.3.2. **Срок** — Лицензия предоставляется бессрочно, без ограничения
срока действия и без необходимости продления.

3.3.3. **Количество Устройств** — одновременное использование Программы
допускается не более чем на двух Устройствах. Пользователь вправе
самостоятельно освободить Устройство средствами Программы и активировать
Ключ на другом Устройстве.

3.3.4. **Способы использования** — воспроизведение Программы, ограниченное
установкой и запуском на Устройстве, а также использование Программы
по её прямому функциональному назначению.

3.4. Программа предоставляется в том виде, в котором она существует
на момент предоставления Лицензии («как есть»).

4.1. Договор считается заключённым с момента Акцепта.

5.1. После поступления оплаты Правообладатель направляет Ключ на адрес

5.2. **Обязательство Правообладателя считается исполненным в момент

«Реквизиты Правообладателя», и Ключ будет направлен повторно.

5.4. Для Активации Ключа требуется подключение к сети «Интернет».

для работы.

5.5. При наличии подключения к сети «Интернет» Программа может
периодически обращаться к серверу Правообладателя для проверки того,

Программы.

6.2. Пробный период предоставляется однократно для одного Устройства.
Для его начала требуется подключение к сети «Интернет».

6.3. По окончании Пробного периода использование Программы возможно
только после Активации Ключа. Созданные Пользователем файлы при этом
