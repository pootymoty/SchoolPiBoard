# Страница покупки и скачивания

`index.html` — самодостаточная страница: стили внутри, скриптов нет.
Свёрстана так, чтобы её можно было положить в прод-сайт и перекрасить.

## Как встроить во Flask

Файл безопасен для Jinja: в нём нет ни `{`+`{`, ни `{`+`%`, ни `{`+`#`
(Jinja разбирает такие последовательности даже внутри HTML-комментариев).
Поэтому его можно положить в `templates/` как есть:

```python
@app.get("/whiteboard")
def whiteboard_page():
    return render_template("whiteboard.html")
```

Если страница статическая — она одинаково хорошо работает и из `static/`.

## Что заменить перед публикацией

Искать в файле слово `ЗАГЛУШКА`:

1. **`action` формы покупки** — адрес сервера лицензий,
   например `https://api.ваш-домен/purchase/start`.
2. **Ссылка на установщик** — путь к `WhiteboardSetup-*.exe`.
3. **Реквизиты в подвале** — ФИО, статус самозанятого, ИНН, почта поддержки.
4. **Раздел «Возврат»** в условиях — текст нужно согласовать.
5. **Цена** — если изменится, поправить в трёх местах: кнопка в шапке,
   блок цены и раздел условий.

## Как это работает

Форма отправляет обычный POST с адресом почты на сервер лицензий, тот
заводит счёт и отвечает переадресацией на страницу оплаты Робокассы.
Ни JavaScript, ни CORS для этого не нужны — а значит, нечему ломаться
при вставке страницы в чужую вёрстку.

Об оплате сервер узнаёт не от браузера, а от самой Робокассы по ResultURL,
поэтому подменить успешную оплату со стороны клиента нельзя.

## Стили

Все цвета и размеры собраны в `:root` в начале `<style>`. Чтобы подогнать
страницу под сайт, обычно достаточно поменять переменные и удалить блок
`<style>` целиком, если у сайта своя система стилей — разметка размечена
классами (`card`, `button`, `steps`, `terms`, `faq`).
