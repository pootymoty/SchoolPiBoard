# «Доска Пи» для iPad и Mac

Нативное приложение на Swift. Одно приложение на iPad и на Mac:
Mac-версия — тот же код через Mac Catalyst, с тем же идентификатором
`online.school-pi.doskapi`, поэтому покупка в App Store одна на обе платформы.

Набор возможностей — как у Windows-версии (`offline/`). Возможности онлайн-доски
(`online/`) сюда не переносятся.

## Состав

| Путь | Что это |
|---|---|
| `project.yml` | описание проекта Xcode для XcodeGen (сам `.xcodeproj` не хранится) |
| `App/` | приложение (SwiftUI + свой холст) |
| `Packages/DoskaPiCore/` | общее ядро: модель доски и формат файла, тесты |

## Формат досок

Тот же JSON, что у Windows-версии (`offline/BoardModels.cs`): поля с большой
буквы, перечисления строками, даты как у .NET. Доска переносится между
Windows, iPad и Mac. Единственное расширение — `PointPressures` (нажим пера
по точкам): его пишет только Apple-версия, Windows его пропускает и рисует
штрих ровной толщиной. Windows-версия при этом не менялась.

## Как собрать и запустить на своём устройстве

На Mac с Xcode 16+:

```bash
brew install xcodegen
cd apple
xcodegen generate
open DoskaPi.xcodeproj
```

В Xcode: цель DoskaPi → Signing & Capabilities → Team (ваш Apple Developer).
Дальше выбрать подключённый iPad или «My Mac (Mac Catalyst)» и нажать Run.

## CI

`.github/workflows/apple-build.yml` на каждую правку в `apple/`: тесты ядра,
сборка под симулятор iPad и под Mac без подписи.

## Этапы

0. Каркас, формат досок, CI — **сделано**.
1. Холст: просмотр досок с Windows как есть.
2. Ввод: перо с нажимом, палец, жесты двумя пальцами, ластик, выпрямление, трекпад.
3. Редактирование: фигуры, текст, картинки, выделение, поворот, группы, отражение, отмена.
4. Список досок, архив, экспорт PNG, передача доски файлом, настройки, темы.
5. Покупка в App Store (разовая, на iPad и Mac), пробный период, восстановление.
6. TestFlight и публикация.
