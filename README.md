# SchoolPiBoard

Два самостоятельных продукта в одном репозитории. Общего кода у них нет
намеренно: разные аудитории, разные домены, разные базы, разные учётные
записи. Роднит их только тема и автор.

| Папка | Продукт | Домен | Место на сервере |
|---|---|---|---|
| `offline/` | Десктопное приложение-доска для Windows, лицензионные ключи | страница продукта | `/var/www/schoolpiboardoff` |
| `online/` | Сайт с онлайн-доской для совместной работы | school-pi-board.online | `/var/www/schoolpiboardon` |

## `offline/` — десктопная доска

WPF-приложение (.NET 8) для рисования на доске, полностью офлайн.
Продаётся по бессрочному ключу за разовый платёж.

| Папка | Что там |
|---|---|
| `offline/` | само приложение (`SchoolPiBoard.csproj`) |
| `offline/installer/` | установщик Inno Setup |
| `offline/server/` | сервер лицензий: ключи, устройства, пробный период, приём оплаты |
| `offline/web/` | страница покупки и скачивания |
| `offline/docs/` | развёртывание сервера ключей, платежи, оферта |

Описание продукта, сборка всех четырёх частей, порядок выпуска и история
версий — в `offline/README.md`. Пошаговый запуск с нуля —
в `offline/docs/runbook.md`.

## `online/` — онлайн-доска

Сайт с совместной работой на доске в браузере, по подписке.

| Папка | Что там |
|---|---|
| `online/server/` | ASP.NET Core + PostgreSQL + Redis: учётные записи, подписки, доски, приглашения, SignalR |
| `online/webapp/` | React + TypeScript: сайт целиком |
| `online/docs/` | развёртывание сайта, автопродление подписки |

Подробности — в `online/README.md`, пошаговый запуск —
в `online/docs/runbook.md`.

## Что где собирается

| Что | Где собирается | Почему так |
|---|---|---|
| Приложение SchoolPiBoard (.exe) | **только на ПК с Windows** | это WPF |
| Установщик SchoolPiBoardSetup.exe | **только на ПК с Windows** | Inno Setup — программа для Windows |
| Сервер ключей | на ПК, на сервере или в CI | обычное приложение .NET |
| Сервер онлайн-доски | на ПК, на сервере или в CI | то же самое |
| Веб-приложение сайта | на ПК или на сервере | нужен Node.js |
| Страницы покупки и оферты | собирать не надо | готовые HTML-файлы |

Сервер, на котором всё работает, слабый, поэтому на нём ничего не собирается:
сервер ключей приезжает готовым архивом из GitHub Actions, остальное
собирается на ПК.

**На ПК с Windows:** .NET 8 SDK, Inno Setup 6 (для установщика), Node.js 20+
(для сайта), Git.

**На сервере:** ASP.NET Core Runtime 8 (именно runtime, SDK не нужен),
PostgreSQL, Redis (только для онлайн-доски), nginx и сертификаты Let's Encrypt.

## Почему это не один проект

Первым появилось десктопное приложение с ключами, вторым — сайт с подпиской.
Соблазн переиспользовать «уже написанный сервер» был, но это связало бы два
продукта общей базой и общими учётными записями: покупатель коробки и
подписчик сайта — разные люди с разными сценариями. Разделение проведено
по папкам и доведено до конца — в онлайн-части нет ни одной строки,
зависящей от десктопной, и наоборот.
