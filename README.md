# Whiteboard — версия 2.0

Полностью переработанный редактор. Ключевое изменение: встроенное выделение
`InkCanvas` заменено собственным холстом с прямой отрисовкой — только так стали
возможны живое превью перетаскивания, панель у объекта, текст внутри фигур
и отсутствие белой подсветки при выделении.

## Установка

Замените **все файлы** проекта — версия несовместима со старой по структуре.
Папки `Themes` больше нет.

```
build.bat
```

Результат: `publish\Whiteboard.exe`.

## Горячие клавиши

## Честные замечания

- **Код не компилировался** в среде разработки — там нет Windows и .NET SDK.
  Проведены статические проверки (XAML как XML, соответствие обработчиков,
  ресурсы, using-директивы, согласованность частей классов) и юнит-тесты
  алгоритмов трансформаций, ластика, выпрямления и зума. Одна ошибка так была
  поймана заранее: `FrameworkElement` не имеет `OnMouseDoubleClick` — двойной
  клик считается вручную.
- **Поворот** объектов — за круглый маркер над рамкой, с Shift шаг 15°.
- **Штрихи при повороте**: точки хранятся без поворота, угол применяется при
  отрисовке — так поворот не накапливает искажения.
- **Экспорт PNG** сохраняет всё содержимое доски, а не видимую область.
- При ошибке запуска подробности пишутся в
  `%APPDATA%\WhiteboardApp\crash.log` и показываются с первопричиной.

## Лицензирование (2.2)

Поверх приложения добавлен слой активации. Логика доски — `BoardCanvas`,
`ItemRenderer`, хранение досок — не затронута.

### Как это работает

1. При запуске `App.OnStartup` спрашивает `LicenseManager.Evaluate()`.
   Пока нет ключа или действующего пробного периода, список досок
   не открывается вовсе — показывается `ActivationWindow`.
2. На этом экране два пути: ввести ключ или взять **3 бесплатных дня**.
   Оба требуют интернета один раз; дальше приложение работает офлайн.
3. Ключ проверяется на сервере, тот привязывает его к отпечатку компьютера
   и возвращает подписанный токен.
4. Раз в сутки при запуске в фоне дёргается `/license/validate` —
   не блокируя интерфейс.
5. Нет сети — молчим и продолжаем работать: офлайн-период **14 дней**
   с последней успешной проверки. Когда он выходит, при следующем запуске
   появляется тот же экран с просьбой проверить лицензию.
6. Заблокировать приложение может только внятный ответ сервера «ключ
   отозван». Отсутствие связи блокировкой не считается.

### Пробный период

3 дня полной версии, один раз на компьютер. Когда они истекают, приложение
не запускается до ввода ключа — доски и настройки при этом остаются на месте.

Злоупотребления пресекаются в три слоя, и решает всё равно последний:

- `license.dat` в профиле пользователя — обычное состояние;
- метки в `HKCU\Software\WhiteboardApp` и `%ProgramData%\WhiteboardApp`
  переживают переустановку приложения: удаление `license.dat` не даёт
  новых трёх дней, а восстанавливает остаток старых;
- **запись на сервере** по отпечатку компьютера и по почте — единственное,
  что нельзя стереть с клиента. Переустановка Windows меняет отпечаток,
  но не почту.

Полностью закрыть обход нельзя (чистая система + новая почта), и это
осознанно: цель — поднять порог, а не воевать с одним настойчивым человеком.

### Адрес сервера

Берётся из переменной окружения `WHITEBOARD_LICENSE_URL` (перекрывает всё),
иначе из поля `LicenseServerUrl` в `%APPDATA%\WhiteboardApp\settings.json`,
иначе — значение по умолчанию из `LicenseOptions.DefaultServerUrl`
(перед выпуском заменить на боевой адрес).

Ключ можно ввести в любой момент: ярлык или `Whiteboard.exe --activate`
открывает экран ввода поверх запуска, то же делает кнопка «Ввести ключ»
в разделе «О программе и лицензии».

## Веб-версия (Фаза 2)

Совместная работа на доске в браузере. Реализован **этап 2a** — каркас,
доступ и права; холст и синхронизация объектов идут следующими этапами.

| Папка | Что там |
|---|---|
| `webapp/` | React + TypeScript + Vite: вход, список досок, участники и роли, комната доски с присутствием |
| `server/` | тот же проект, что и сервер лицензий: учётные записи, подписки, доски, участники, SignalR-хаб |

### Что уже работает

- Регистрация и вход, пробная подписка на 7 дней сразу после регистрации.
- Список досок, создание и удаление, приглашение по почте с выбором роли
  (владелец / редактор / просмотр), смена роли, удаление участника.
- Комната доски по SignalR: видно, кто сейчас в доске; при обрыве связи
  клиент переподключается и получает состояние комнаты заново.

### Как устроен доступ

Роль участника проверяется на сервере при каждом обращении — и в REST,
и в хабе, через один и тот же `BoardService.GetRoleAsync`. Фронтенд прячет
кнопки, которые роли не положены, но это удобство, а не защита: скрытая
кнопка ничего не запрещает.
